How it works

From listing to valuation
in four steps

A complete ML pipeline runs behind every prediction — not just a model file.

1
Data Ingestion
Raw CardDekho CSV → EDA cleaning → stratified 80/20 split → artifact store.
2
Validation
Schema check on 11 columns. KS drift detection (p < 0.05) on all numerical features.
3
Transformation
StandardScaler + OneHotEncoder via ColumnTransformer. 10 features → 44 inputs.
4
ANN Prediction
44 → 128 → 128 → 1. log1p target, expm1 at inference. Actual rupees returned.
Under the hood

Built with production
MLOps standards

🧠
Neural Network Regression
TensorFlow/Keras ANN with BatchNormalization + Dropout. EarlyStopping(patience=10) restores best weights. MAE loss for rupee-interpretable training.
🔍
GridSearch Architecture Tuning
KerasRegressor + GridSearchCV searches neurons, layers, and epochs. Best params used for final training. Reproducible and auditable.
📊
MLflow + DagsHub Tracking
Every run logs MAE, RMSE, and R² for both train and test sets. Full experiment history on DagsHub. Model versioned on HuggingFace Hub.
⚡
Zero-Cold-Start Deployment
Model pulled from HuggingFace Hub on startup — never committed to git. Preprocessing + model served via FastAPI with lifespan event handler.
🔄
Retrain on Demand
Hit GET /train and the full pipeline reruns — ingestion → validation → transformation → ANN training → MLflow log → HuggingFace push. No manual steps.
